# Nhạc nền

Đặt tệp `.mp3` / `.wav` / `.m4a` **có quyền sử dụng** vào đây (nhạc tự sản xuất, nhạc mua bản quyền, thư viện nhạc
miễn phí bản quyền của nền tảng). Nhạc có bản quyền dễ bị TikTok / Facebook tắt tiếng hoặc gỡ video.

Phần mềm không kèm sẵn nhạc. Âm lượng nhạc chỉnh ở `[video].am_luong_nhac` (mặc định 0,12 để không lấn giọng đọc).
